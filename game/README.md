# FT Manager 26/27

A standalone, mobile-first fantasy football club management game.

## Features
- Manage a fantasy squad, create players, sign transfer targets, and sell players.
- Choose formation, mentality, build-up style and defensive line.
- Simulate matches with player ratings, fitness, tactics and home advantage.
- Track fixtures, league table, finances, supporter satisfaction and news.
- Local browser autosave with JSON export/import.

## Run
Open `index.html` in a modern browser. No build tools or external libraries are required.

## Notes
This starter game is independent of the NFTA Official app and its existing Supabase database. Match data and players are game simulation data; cross-device cloud saves and online accounts are not yet enabled.
